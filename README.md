# Open Science and AI in Research Software Engineering - Grupo 6

Este es el repositorio del **Grupo 6**.

El objetivo es crear un **grafo de conocimiento** de publicaciones científicas en el ámbito de **Astrophysics of Galaxies**.

## Integrantes

- Michele Barrera Colmenares
- Jorge Blanco Carrasco
- Maria Agostina Squillari
- Andrés Pecker Matesanz

## 1. Objetivo general

El objetivo del proyecto es construir un **Knowledge Graph** de publicaciones científicas sobre galaxias en astrofísica para facilitar la exploración de líneas de investigación, objetos astronómicos estudiados, relaciones temáticas entre artículos, colaboración entre autores e instituciones y financiación reconocida en los trabajos.

## 2. Caso de uso

El KG permitirá responder preguntas como:

- ¿Qué papers estudian una misma galaxia?
- ¿Qué papers son similares por su abstract aunque no estudien exactamente el mismo objeto?
- ¿Qué autores e instituciones trabajan sobre las mismas galaxias o temas?
- ¿Qué organizaciones financian investigación sobre determinados objetos astronómicos?
- ¿Qué topics emergen en el corpus y qué papers pertenecen a cada topic según un modelo de IA evaluado?

## 3. Fuentes

### OpenAIRE

Se utilizará para recuperar publicaciones, metadatos, proyectos, funding y relaciones de investigación.

### ROR

Se utilizará para identificar y normalizar organizaciones.

### DOI

Se utilizará como identificador persistente del paper cuando esté disponible.
